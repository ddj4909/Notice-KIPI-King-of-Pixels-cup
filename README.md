# KIPI 공지 / 패치노트

인게임 타이틀 공지 패널이 이 저장소의 `notice.txt`, `patch-notes.txt`를 그대로 불러옵니다.

## 색 규칙

세 가지 색만 사용합니다. 본문 설명에는 색을 넣지 않습니다.

| 용도 | 색 | 태그 |
|---|---|---|
| 대제목 (날짜, 이벤트) | 금색 | `<size=112%><color=#FFD54F><b>제목</b></color></size>` |
| 소제목 (항목 분류) | 하늘색 | `<size=108%><color=#7EC8FF><b>소제목</b></color></size>` |
| 키워드 (기능명, 키, 태그명) | 금색 | `<color=#FFD54F><b>키워드</b></color>` |
| 주의 (경고, 제약, 옛 조작) | 빨강 | `<color=#FF8A80>주의 문구</color>` |

- 대제목과 키워드는 같은 금색입니다. 크기로 구분합니다.
- 소제목은 항상 하늘색으로 통일합니다. 항목마다 다른 색을 쓰지 않습니다.
- 키워드는 기능 이름만 칠합니다. 문장 전체를 칠하지 않습니다.
- 주의는 경고 문장 또는 더 이상 쓰지 않는 키만 칠합니다.

## 2026.9.15

### 공지
- **친구와 함께 봇을 이겨라** 이벤트 진행
- 초급 / 중급 / 고급 봇을 이기면 인당 음료 1잔, 난이도당 선착순 1팀

### 패치
- 캐릭터 선택창 스킬 키 안내를 스페이스바로 변경
- 연습 모드에서 킥 방향 안내 문구 추가

## 2026.9.13

### 공지
- 대기실에서 초급 / 중급 / 고급 봇과 캐릭터를 추가해 인원과 관계없이 플레이 가능

### 패치
- 대기실 봇 추가
- 초급 / 중급 / 고급 난이도와 캐릭터 선택
- 같은 팀 동일 캐릭터 중복 선택 불가
- 달리기 속도 증가

## 2026.9.9

인게임 패널에서는 숨기고, 기록만 남깁니다.

### 패치
- 네임태그 / 팀태그 가시성 개선
- 커서 인디케이터 크기 증가
- 공이 화면 밖으로 나가면 위치 표시
- 공이 가려져도 실루엣으로 위치 확인
- 스킬 키를 `R`에서 `스페이스바`로 변경
